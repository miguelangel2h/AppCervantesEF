# Molinos de Silencio

Aplicación web para controlar el ruido en clase, ambientada en Miguel de Cervantes y *Don Quijote de la Mancha*.

- **Sonómetro**: usa el micrófono (no graba ni envía nada). Las aspas del molino giran más rápido cuanto más ruido hay; si se supera el límite, el molino se convierte en gigante.
- **Yelmos de Mambrino**: la clase pierde un yelmo cada vez que el ruido se queda en rojo durante unos segundos.
- **Reloj de arena**: temporizador con tiempos rápidos (1, 5, 10, 15 y 30 minutos) y sonido al terminar.
- **Música del escudero**: pega enlaces de YouTube (vídeos o listas). Opción de bajar el volumen cuando haya mucho ruido.
- Ajustes de sensibilidad, límite y tolerancia; tema claro u oscuro; pantalla completa.

Es un solo archivo, `index.html`. Para que funcionen el micrófono y YouTube hay que abrirlo desde una web con https (por ejemplo, GitHub Pages), no como archivo local.
